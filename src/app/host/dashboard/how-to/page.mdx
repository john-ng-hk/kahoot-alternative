# How to play the game

This app is a simple multi-player real-time quiz game just like Kahoot. Each player joins the game from their phone and whoever gets the highest point wins.

## Steps

1. Host creates a game by clicking the "Start Game" button.
2. Host shares the QR code with the players. 
3. Players scan the QR code and enter the game with a nickname.
4. Once all the players have joined, the host can start the game.
5. A question will be displayed on the host's screen and the players' device. After 5 seconds, the choices are revealed, and the players can choose their answer by tapping the choice.
6. After each question, the host's screen shows the top 5 players. Players who move up or down show a ▲ or ▼. The host clicks "Continue" for the next question.
7. When all the questions are done, the final results are displayed on the host's screen.

## End a game early

Click "End game" on the game screen, or "End" under "Active games" on the dashboard. The game stops, players see a thank-you screen, and the host screen shows the results so far. "Resume" under "Active games" reopens a game that is not finished.

A quiz that has games cannot be edited. Open the quiz and click "Delete games" to unlock it. This also deletes the results of those games. You can also duplicate the quiz and edit the copy.

## Import quizzes

On "My quizzes", click "Import" to create several quizzes from one JSON file. Each question has 2 to 4 choices, and `correct` is the position of the right choice, starting at 0. If the file has an error, nothing is imported. The import page has a format guide and an example file.

## Signing in

Hosts sign in with an email address. Enter the code from the email, or open the link in it. If the link says to sign in again, use the code.

## Tips for winning

The faster you answer, the more points you get. So, be quick!
